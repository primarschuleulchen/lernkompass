# Lernkompass

Übersicht über die digitalen Helfer von Primarschuleulchen: offen für alle, ohne Anmeldung und ohne Datenweitergabe.

- `index.html`: die Übersichtsseite mit den Tool-Karten
- `style.css`: Gestaltung (Farben und Schriften wie Tagesfolie und Hausaufgabenheft im Knobelnest)
- `schriften/`: Nunito und Patrick Hand, lokal abgelegt (SIL Open Font License), damit nichts von Google geladen wird

Das Knobelnest ist ein eigenes Projekt (mit Anmeldung und Datenbank) und wird von hier nur verlinkt.
